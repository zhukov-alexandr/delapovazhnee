# Стоп-Штамп (Slop Stop)

Навык для удаления характерных ИИ-штампов из текста.

<img width="3840" height="2160" alt="Banner Slop Stop" src="https://github.com/user-attachments/assets/c7d3abad-4e15-48e5-8915-9ac5aa02317b" />

## Что это такое

ИИ-тексты имеют паттерны: предсказуемые фразы, структуры, ритм. Как только вы их замечаете, вы начинаете видеть их везде. Этот навык учит Claude (или любую другую LLM) избегать их.

## Структура навыка

```text
slop-stop/
├── SKILL.md              # Основные инструкции
├── references/
│   ├── phrases.md        # Фразы, которые нужно удалить
│   ├── structures.md     # Структурные паттерны, которых следует избегать
│   └── examples.md       # Примеры трансформаций «До/После»
├── README.md
└── LICENSE
```
## Быстрый старт

**Claude Code:** Добавьте эту папку как навык (skill).

**Claude Projects:** Загрузите `SKILL.md` и справочные файлы (из папки references) в базу знаний проекта.

**Кастомные инструкции (Custom instructions):** Скопируйте основные правила из `SKILL.md`.

**API-запросы (API calls):** Включите `SKILL.md` в ваш системный промпт. Справочные файлы загружайте по мере необходимости.

## Что он отлавливает

**Запрещенные фразы** — Вводные конструкции («прочистка горла»), костыли для привлечения внимания, корпоративный жаргон. См. `references/phrases.md`.

**Структурные клише** — Бинарные контрасты, драматичная фрагментация, риторические подводки. См. `references/structures.md`.

**Стилистические привычки** — Тройные перечисления, немедленные ответы на заданные вопросы, метрономные (однообразные) концовки.

## Оценка (Scoring)

Оцените текст от 1 до 10 по каждому параметру:

| Параметр        | Вопрос                                              |
| --------------- | --------------------------------------------------- |
| Прямолинейность | Это утверждения или анонсы того, что будет сказано? |
| Ритм            | Разнообразный или как под метроном?                 |
| Доверие         | Уважает ли текст интеллект читателя?                |
| Аутентичность   | Звучит ли как человек?                              |
| Плотность       | Можно ли что-то вырезать без потери смысла?         |

Ниже 35/50: отправить на переработку.
