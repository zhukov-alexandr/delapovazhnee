# Структуры, которых следует избегать

## Бинарные контрасты

Они создают фальшивую драму. Выражайте мысль прямо.

| Паттерн                                    | Проблема                       |
| ------------------------------------------ | ------------------------------ |
| «Не потому, что X. А потому, что Y.»       | Читаемый за версту разворот    |
| «Проблема не в [X]. Проблема в [Y].»       | Шаблонный рефрейминг           |
| «Ответ — не X. Это Y.»                     | Предсказуемый финт             |
| «Кажется, что это X. На самом деле это Y.» | Клише «установка/разоблачение» |
| «Вопрос не в X. А в Y.»                    | Риторическая уловка            |
| «Не X. А Y.»                               | Механический контраст          |
| «Дело не в этом. Дело в том.»              | Та же формула, другие слова    |
| «Перестает быть X и становится Y»          | Фальшивая арка трансформации   |

**Вместо этого:** Заявляйте Y прямо. «Проблема в Y». «Здесь важен Y».

## Драматическая фрагментация

Обрывки предложений ради акцента читаются как искусственная глубокомысленность.

| Паттерн                                          | Проблема                      |
| ------------------------------------------------ | ----------------------------- |
| «[Существительное]. Вот и все. В этом вся суть.» | Перфомативная простота        |
| «X. И Y. И Z.»                                   | Стаккато-драма                |
| «Это открывает кое-что еще. [Слово].»            | Искусственное озарение        |
| «Точка.» (отдельным предложением в конце)        | Наигранная безапелляционность |

**Вместо этого:** Пишите полными предложениями. Доверьтесь содержанию, а не внешней подаче.

## Риторические подводки

Они анонсируют инсайт, вместо того чтобы дать его.

| Паттерн                                    | Проблема                     |
| ------------------------------------------ | ---------------------------- |
| «Что, если я скажу вам, что [рефрейминг]?» | Поза Сократа                 |
| «Вот что я имею в виду:»                   | Лишнее превью                |
| «Подумайте об этом:» / «Согласитесь,...»   | Снисходительная подсказка    |
| «И это абсолютно нормально.»               | Ненужное разрешение/утешение |

**Вместо этого:** Сразу переходите к сути. Позвольте читателям самим сделать выводы.

## Шаблонные конструкции

| Паттерн                                       | Проблема                                     |
| --------------------------------------------- | -------------------------------------------- |
| «К тому моменту, когда случилось X, я был Y.» | Нарративный шаблон                           |
| «Тот самый X, который не Y»                   | Слишком уклончиво. Скажите прямо: «X сломан» |

## Ритмические паттерны

| Паттерн                                                   | Как исправить                                   |
| --------------------------------------------------------- | ----------------------------------------------- |
| Списки из трех элементов                                  | Оставьте два элемента или один                  |
| Немедленные ответы на свои же вопросы                     | Дайте вопросам «подышать» или удалите их        |
| Абзацы, начинающиеся с «Итак,» или «Таким образом,»       | Начинайте сразу с контента                      |
| Предложения, начинающиеся с «Послушайте,» или «Смотрите,» | Удалите                                         |
| Каждый абзац заканчивается «панчем»                       | Разнообразьте концовки                          |
| Тире перед развязкой или инсайтом                         | Используйте точки или запятые                   |
| Фрагментация стаккато                                     | Не нагромождайте короткие, рубленые предложения |
| Многоточия ради драматической паузы...                    | Используйте точки                               |
| «Не всегда. Не идеально.»                                 | Перестраховка, замаскированная под честность    |

## Словесные паттерны

| Паттерн                                                                                                   | Проблема               |
| --------------------------------------------------------------------------------------------------------- | ---------------------- |
| Абсолюты (всегда, никогда, все, каждый, никто)                                                            | Ложная авторитетность  |
| Затасканные ИИ усилители (глубоко, поистине, фундаментально, по своей сути, просто, буквально, неизбежно) | Пустая эмоциональность |
| Типичные русские ИИ-усилители (максимально, несомненно, безусловно, крайне важно)                         | Канцелярский пафос     |
