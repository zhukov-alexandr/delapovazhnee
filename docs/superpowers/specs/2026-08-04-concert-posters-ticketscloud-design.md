# Афиши тура и виджеты Ticketscloud — дизайн

## Цель

Обновить концертный раздел главной страницы: показать пять новых городских афиш на десктопе, общую интерактивную афишу на мобильных устройствах и открывать покупку билетов через виджеты Ticketscloud.

## Десктопная версия

- Сохранить существующую карточную подачу концертного раздела.
- Разместить пять карточек в один горизонтальный ряд без карусели и переноса: Уфа, Екатеринбург, Новосибирск, Москва, Санкт-Петербург.
- В каждой карточке показать соответствующий новый PNG и краткую информацию о городе, дате и площадке.
- Существующую ссылку «Билеты» заменить кнопкой Ticketscloud, сохранив визуальный стиль сайта.

## Мобильная версия

- Скрыть пять отдельных городских карточек.
- Показать файл `все афиши.png` на всю доступную ширину контейнера.
- Наложить на пять строк списка городов пять прозрачных кнопок. Кликабельна вся строка с датой и названием города, а не только текст.
- Каждая зона открывает тот же Ticketscloud-виджет, что и кнопка соответствующего города на десктопе.
- Добавить доступные текстовые названия кликабельных зон для экранных дикторов и видимый фокус при навигации клавиатурой.

## Ticketscloud

Подключить один раз скрипт:

```html
<script src="https://ticketscloud.com/static/scripts/widget/tcwidget.js"></script>
```

Использовать следующие события:

| Город | `data-tc-event` |
| --- | --- |
| Уфа | `6a46a070983da59ac77d8ccd` |
| Екатеринбург | `6a4b6ed19f4bf9931aca2868` |
| Новосибирск | `6a7085d06d1bdc42b48fdf81` |
| Москва | `6a186cb9dd25944b28dbb181` |
| Санкт-Петербург | `6a19b3b6f4606596ec821030` |

Все десять точек входа — пять десктопных кнопок и пять мобильных зон — используют предоставленный общий `data-tc-token` и атрибут `data-tc-utm_source="site"`.

## Изображения

- Оптимизировать шесть добавленных PNG: пять городских афиш и `все афиши.png`.
- Сохранить текущие имена и формат PNG, чтобы не менять переданные исходные ссылки.
- Каждый итоговый файл должен весить не более 300 КБ.
- Уменьшить пиксельные размеры до значений, достаточных для фактического отображения на сайте, и применить палитровое сжатие, сохранив разборчивость текста и характер бумажной текстуры.

## Адаптивность и локализация

- Пять карточек отображаются одним рядом только шире мобильного breakpoint сайта.
- На мобильном breakpoint показывается только общая афиша.
- Существующий переключатель RU/EN/ZH продолжает переводить подписи и доступные названия; данные Ticketscloud не меняются при переключении языка.
- Концертный раздел сохраняет текущую визуальную стилистику, отступы, наклоны карточек и цвет кнопок.

## Проверка

- Автоматический тест страницы проверяет наличие пяти уникальных event ID, общего токена, UTM-атрибута на всех десяти элементах и единственного подключения `tcwidget.js`.
- Проверяется наличие обеих адаптивных компоновок и всех шести новых изображений.
- Отдельная проверка подтверждает размер каждого нового PNG не более 300 КБ.
- После реализации выполняются полный набор тестов и визуальная проверка главной страницы на десктопной и мобильной ширине.
