# Визуальные направления — три поверхности

**Дата:** 2026-07-01
**Статус:** утверждено заказчиком; **реализовать на UI-тасках (12–15 + отдельная таска лендинга), не раньше.**

Проект намеренно несёт **три разные айдентики**. Не смешивать.

| Поверхность | Айдентика | Кратко |
|---|---|---|
| **Игра** (`/`) | Летний закатный пиксель (PS1/Sega) | тёплая, играбельная, аркадная |
| **Лендинг** (`/home`) | «Рукописная лирика на рваной бумаге» — по обложке прошлого сингла | холодная, полуночно-синяя, аналоговая, интимная |
| **Админка** (`/admin`) | Обычная, без излишеств | нейтральный функциональный дашборд |

---

## 1. Игра — Summer Sunset Pixel (основная эстетика)

Бриф задаёт вектор жёстко (пляжный закат, PS1/Sega, крупные пиксели, дизеринг,
большое солнце над морем, тёплый градиент неба, параллакс, кириллический пиксель-шрифт).
Исполняем точно.

### Палитра (лимитированная, 6 + акцент)

```
--night  #241539   верх неба, скримы оверлеев
--grape  #6D2E8B   средняя полоса неба, тени
--flare  #FF5D73   закатный коралл (основной тёплый)
--sun    #FFD35C   солнце, счёт, хайлайты
--sand   #F2C078   песок, панели
--foam   #FFF4E2   кремовый текст/бумага
--arcade #2FE6D6   ХОЛОДНЫЙ циан — CTA, кнопки, фокус (единственная холодная нота)
--ink    #2A1533   тёмный текст на светлых панелях
```

**Осознанный риск:** циан `--arcade` — единственный холодный акцент на сплошном тёплом
закате; интерактив (Играть, Пресейв, фокус, счёт) должен выпрыгивать из сцены. CRT-контрапункт
эпохи, спасает от тёпло-монохромного клише.

### Типографика (все с кириллицей)

- **Display — `Handjet`** (вариативный точечно-матричный): крупные заголовки. С ограничением.
- **Body/UI — `Pixelify Sans`**: кнопки, подписи, инструкции.
- **Data — `VT323`** (моноширинный терминальный): счёт HUD, числа.

### Signature — «дизеренное закатное солнце»

Большое пиксельное солнце с горизонтальными дизер-полосами (80s-закат с «зазорами»).
Паттерн полос + палитра эхом повторяются: мини-диск под счётом HUD, полосатая текстура
на главных кнопках, тем же бэнд-градиентом — бары дневного графика (если бы админка была
ретро — но она обычная, см. §3, так что бары солнца только в игре), дизер-ряды как разделители.
Одна запоминающаяся вещь; всё вокруг тихо. Уводит от неон-синтвейв-клише в честный PS1-пиксель:
крупные пиксели, ordered dithering, лимитированная палитра. Никаких светящихся вектор-сеток.

### Экраны

- **Старт:** за translucent-скримом — живая сцена (параллакс-закат + бегун покачивается);
  заголовок (Handjet) с лёгким свечением солнца, строка инструкции, крупная кнопка «ИГРАТЬ»
  (`--arcade`); для **варианта A** — CTA-блок (QR + «Сделать пресейв»).
- **HUD:** минимум — счёт (VT323) на мини-диске солнца сверху; кнопка mute (пиксельный динамик);
  ссылка «На главную» → `/home`.
- **Game Over:** центрированная панель, «ИГРА ОКОНЧЕНА» (Handjet), счёт, «ЕЩЁ РАЗ»;
  для **варианта B** — CTA-блок (QR + «Сделать пресейв»).

### Адаптивность

Обе ориентации, тач-цели ≥44px, `image-rendering: pixelated`, DPR, safe-area. См. план §7.

## 2. Лендинг — «Рукописная лирика на рваной бумаге» (по обложке прошлого сингла)

Заказчик прислал обложку прошлого сингла как референс. **Лендинг переделывается в её стиле**
(НЕ в закатном). Реализуем на отдельной UI-таске, содержимое (релиз-ссылки, тур, соцсети) —
то же, что сейчас в `templates/home.html`, но реоформленное в этот мир.

### Разбор обложки-референса

- **Фон:** глубокий полуночно-синий / navy, почти чёрный сверху, чуть более светлый холодный
  синий у «горизонта» за горами.
- **Передний план:** белая/кремовая мятая бумага, **рваный верхний край** формирует зубчатый
  силуэт горной гряды на фоне тёмного неба.
- **Текстура:** бумага плотно исписана мелким **рукописным** русским текстом (строки песни).
- **Настроение:** холодное, интимное, меланхоличное, аналоговое/лоу-фай. Монохром-синий +
  бумажный белый. Противоположность тёплой играбельной игре.

### Палитра (черновая, уточнить по файлу обложки)

```
--ld-sky-top   #0B1524   почти чёрный верх неба
--ld-sky       #16273F   основной navy
--ld-sky-glow  #24405F   холодное свечение у горизонта
--ld-paper     #EDE7DA   бумага (кремово-белая)
--ld-paper-sh  #B9C2CC   холодная синеватая тень бумаги
--ld-ink       #1B2430   рукописный текст / основной текст
```

### Типографика

- **Акцент/заголовки — рукописный кириллический** (кандидаты: `Caveat`, `Marck Script`,
  `Bad Script` — все с кириллицей), очень сдержанно, перекликается с почерком на обложке.
- **Body — тихий чистый сан-сериф** с кириллицей (напр. текущий Roboto с лендинга или
  аккуратный гротеск) для структуры/ссылок. Холодно, спокойно.

### Реализация (заметки)

- **Нужен файл обложки в репозитории** (положить в `static/home/`, напр. `cover.jpg`) —
  как герой/фон/текстура. ⟵ ПОПРОСИТЬ У ЗАКАЗЧИКА.
- Рваный край бумаги — через сам image, либо SVG/`clip-path` (зубчатый полигон) поверх
  бумажного слоя.
- Секции (Релиз / Тур / Соцсети) — как «слои бумаги» на тёмно-синем; ссылки-стримингов и
  билетов сохранить.
- **Не трогать** внешние интеграции лендинга: Яндекс.Метрика, UTM-скрипт, ссылки — оставить.

## 3. Админка — обычная, без излишеств

**Явное требование заказчика:** админка/дашборд — **обычные, без излишеств**. Это
**переопределяет** пункт брифа «админка в той же ретро-эстетике».

- Нейтральный функциональный вид: системный шрифт-стек, светлый фон (белый/светло-серый),
  простые таблицы с рамками, базовые CSS-бары, стандартные кнопки. Читабельно, «намеренно скучно»,
  быстро сканируется.
- Метрики и раскладка — как в плане (колонки A/B рядом, CVR, дневные бары, строка
  Байес P(B>A) + Fisher p, экспорт CSV) — просто в простом стиле.
- Практически: минимальный `static/css/admin.css` из Задачи 8 **и есть** финальный вид админки.
  Task 15 (визуальный проход) **не** ретро-скинит админку.
